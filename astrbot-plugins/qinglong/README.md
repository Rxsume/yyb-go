# 青龙侧脚本

AstrBot 插件依赖的青龙侧脚本。只收脚本代码本身，不含任何 Cookie、
token、密钥、环境变量值——凭证全部走青龙环境变量，见各脚本头部的
环境变量说明。

传进青龙的办法：面板“脚本管理 → 上传”，或把文件放进青龙容器
`/ql/data/scripts/`，再按下面的命令建定时任务。

## 没收进来的

- **青龙任务 200（酷狗概念版登录 / token）**：脚本本地没有副本，只在
  青龙里，未收进仓库。如需备份，从青龙面板把任务 200 的脚本导出来再补。
- 古茗、快手、DDNSTO 等其他任务的脚本与本仓库无关，不收。
- `elm_cookie_tool.py` / `elm_cookie_tool_minis.py`（Minis 浏览器登录
  工具）是手动取 Cookie 的辅助工具，不是青龙定时任务脚本，不收。
